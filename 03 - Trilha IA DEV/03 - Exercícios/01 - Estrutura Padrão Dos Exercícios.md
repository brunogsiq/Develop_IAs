# Estrutura padrão dos exercícios

> Todo módulo usa a mesma sequência de exercícios. Repetir o mesmo formato aumenta a retenção: você aprende o conteúdo e, ao mesmo tempo, um método de estudo.

## A sequência

| # | Tipo | Objetivo | Exemplo |
|---|------|----------|---------|
| 1 | **Guiado** | Executar junto com o material, seguindo os passos | Repetir o passo a passo do módulo |
| 2 | **Fixação** | Fazer de novo sem consultar o material | Depois de Git: criar branch, commit, merge e push sozinho |
| 3 | **Comparação** | Resolver o mesmo problema em ferramentas diferentes | Claude × ChatGPT × Gemini × Cursor: quem explicou, escreveu, programou e documentou melhor? |
| 4 | **Pesquisa** | Consultar a documentação oficial, nunca só a IA | O que a documentação diz? O que mudou? Qual versão está vigente? Quais limitações existem? |
| 5 | **Debug** | Encontrar e corrigir um erro | Onde está, por que aconteceu, como reproduzir, como corrigir, como evitar regressão |
| 6 | **Refatoração** | Transformar código ruim em código legível, seguro e sustentável | Explicar o que mudou, por que e qual o ganho |
| 7 | **Integração** | Aplicar o conteúdo no [projeto principal](<../02 - Projeto/01 - Projeto Principal.md>) | Aprendeu Docker? Containerize o projeto |
| 8 | **Mini projeto** | Criar algo pequeno e completo | Landing page + repositório + container + documentação |
| 9 | **Desafio** | Resolver sem passo a passo, só com a documentação | |
| 10 | **Desafio avançado** | Integrar várias tecnologias | Claude + Cursor + GitHub + Docker + Playwright |
| 11 | **Revisão** | Refletir sobre o aprendizado | O que aprendi? Onde tenho dificuldade? O que preciso revisar? |
| 12 | **Autoavaliação** | Dar nota de 1 a 5 | Ver abaixo |

## Autoavaliação

```text
Conhecimento: ☆☆☆☆☆
Prática:      ☆☆☆☆☆
Confiança:    ☆☆☆☆☆
Velocidade:   ☆☆☆☆☆
```

Troque `☆` por `★` conforme a nota. Repita a autoavaliação ao revisitar o módulo para ver a evolução.

## Ficha de cada exercício

Para transformar a lista em prática guiada, registre quatro blocos em cada exercício:

```markdown
### Exercício: <nome>
- **Objetivo:** o que será aprendido
- **Critérios de aceitação:** como saber que terminou com sucesso
- **Erros comuns:** problemas frequentes e como evitar
- **Material de apoio:** link da documentação oficial
```

Os exercícios específicos de cada módulo estão em [02 - Exercícios Por Módulo](<02 - Exercícios Por Módulo.md>).
