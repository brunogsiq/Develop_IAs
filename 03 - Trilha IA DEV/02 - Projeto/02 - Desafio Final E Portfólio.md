# Desafio final e portfólio

## Desafio final

Criar uma funcionalidade completa **sem tutorial**. A IA pode ser usada como copiloto.

Ao final, você deve conseguir explicar:

| Tema | O que explicar |
|------|----------------|
| Requisito | O que foi pedido e quais dúvidas surgiram |
| Arquitetura | Como a solução foi organizada e por quê |
| Código | Cada parte relevante, inclusive o que a IA gerou |
| Banco | Modelo de dados e índices |
| Decisões | Alternativas consideradas e o motivo da escolha |
| Testes | O que foi testado, como e o que ficou de fora |
| Riscos | O que pode dar errado em produção |
| Bugs | O que foi encontrado e como foi corrigido |
| Pipeline e deploy | Como o código chega a produção |
| Documentação | Onde está e para quem foi escrita |

> A funcionalidade só está concluída quando você consegue explicar tecnicamente o que foi produzido.

## Portfólio

### Entregáveis

- [ ] Repositório público no GitHub
- [ ] README profissional (objetivo, stack, como rodar, arquitetura, decisões)
- [ ] Documentação técnica e Wiki
- [ ] Diagramas de arquitetura (Mermaid)
- [ ] Cenários BDD e plano de testes
- [ ] Automação de testes
- [ ] Documentação da API (Swagger/OpenAPI)
- [ ] Pipeline de CI/CD
- [ ] Docker
- [ ] Deploy acessível
- [ ] Evidências (relatórios de teste, prints)
- [ ] Perfil do LinkedIn atualizado com o projeto
- [ ] Vídeo demonstrativo (opcional)
- [ ] Artigo técnico sobre o que aprendeu (opcional)

### Dicas

- Mostre **como** você usou IA: prompts, regras do projeto, o que funcionou e o que precisou corrigir. Isso diferencia você de quem só gerou código.
- Um projeto bem documentado vale mais do que vários projetos pela metade.
- Nunca publique dados reais, chaves de API ou código de cliente.
