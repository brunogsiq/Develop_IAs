# Checklist de competências

> O que você deve conseguir fazer ao concluir a trilha. Use como autoavaliação a cada fase. As competências gerais (fundamentos, prompt, assistentes, segurança e privacidade) estão nos checklists da [Trilha IA Geral](<../../01 - Trilha IA Geral/README.md>).

## IDEs com IA (Cursor / Copilot)

- [ ] Trabalhar com contexto e regras de projeto
- [ ] Usar o modo agente
- [ ] Refatorar, depurar e gerar testes

## Claude Code

- [ ] Navegar e analisar um projeto
- [ ] Alterar arquivos e executar comandos com permissões controladas
- [ ] Revisar mudanças e trabalhar com Git
- [ ] Criar Skills

## Construir com IA

- [ ] Chamar um modelo pela API com tool calling
- [ ] Construir um servidor MCP
- [ ] Montar e avaliar um RAG
- [ ] Construir um agente e uma automação

## Desenvolvimento

- [ ] Front-end, back-end e API
- [ ] Banco de dados
- [ ] Autenticação
- [ ] CRUD completo

## Git e GitHub

- [ ] Branch, merge e rebase
- [ ] Pull Request e Code Review
- [ ] GitHub Actions

## QA

- [ ] Análise de requisitos e BDD
- [ ] Plano e casos de teste
- [ ] Regressão e testes de API
- [ ] Automação

## DevOps

- [ ] Docker
- [ ] CI e CD
- [ ] Deploy, logs e rollback

## Gestão

- [ ] Jira e Trello
- [ ] Backlog, sprint e bugs

## Portfólio

- [ ] Projeto público com README e documentação
- [ ] Automação e pipeline
- [ ] Deploy acessível
